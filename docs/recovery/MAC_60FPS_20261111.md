# Mac local playtest — 2026-11-11

Apple Silicon Release/IPO/OpenBIOS build with 7,459 linked native overlays.
The local race package selects 9x internal rendering (3834×2160 at 16:9), the
60-FPS GP enhancement and rewind. PGXP, Max Detail, effects, custom Select/Back
menu/settings and Steam Controller fixes remain. Owner saves are not bundled
or overwritten. This is an ad-hoc signed local playtest, not a public release.

## Results

Exact command rewind replaces repeated guest replay while the button is held.
It redraws recorded commands and texture state at gameplay resolution, with no
video history or resolution reduction. Machine state is reconstructed once on
release. All 24 full internal images in the parity run matched; the selected
RAM state matched with zero differing words. Hold/release and forward-image
handoff passed. See [rewind details](../REWIND_PLAYBACK.md).

The visible 120-second Helter Skelter race measured 58.92 forward FPS and 59.57
backward updates/s. A subsequent 30-second run measured 60.01 forward FPS and
58.99 backward updates/s. The physical display is 1440p/75 Hz; these are internal
2160-line results. Tunnel, sky, ground and HUD samples were inspected without
observing the former center pixelation or obvious seams/order faults. They are
bounded evidence, not an all-course guarantee.

Long-hold release still has a measured 0.38–0.51-second transition pause including
up to 100 ms of polling. Perfect sustained 60 FPS is not established. Other CPU
work was present; no unrelated processes were stopped. The owner requested
wrapping up instead of further repeated performance testing.

The final executable is identified in the [receipt](MAC_60FPS_20261111.json).
Release build, all 39 CTests, isolated custom-menu/settings/race smoke and a short
run of the default rewind backend are the final delivery checks. Physical Steam
Controller behavior remains device-dependent; synthetic controls/menu checks
are identified separately. The independent scene renderer's R4 producer is
still unconnected; this build uses qualified guest draw production.
