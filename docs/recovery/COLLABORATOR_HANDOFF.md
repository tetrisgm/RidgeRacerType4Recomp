# Rebuild current master

Use the [current clone/build instructions](../../README.md#build-on-the-mac).
Follow the committed submodule pins with `git submodule update --init --recursive`.
There is no recovery branch prerequisite. All development and cross-building
happens on the Mac; STEAMBOX receives finished builds only.

The [original handoff](../archive/COLLABORATOR_HANDOFF-before-consolidation-20261108.md)
is historical evidence, not current machine-access or workflow instructions.
The owner's optional [4K/8x profile](approved-4k.toml) remains a reference;
never overwrite their explicit settings or native saves.
